# Publishing a Blog Post

Create a Markdown file in `_posts/` using this filename format:

```text
YYYY-MM-DD-your-article-title.md
```

For example:

```text
_posts/2026-09-04-how-i-review-defi-protocols.md
```

Start the file with this front matter, then write the article in Markdown:

```markdown
---
layout: post
title: "How I Review DeFi Protocols"
date: 2026-09-04
---

Your article starts here.
```

Jekyll will automatically add it to the `/blog/` page. Clicking the title opens the full article.
